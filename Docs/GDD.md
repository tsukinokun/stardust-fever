# Stardust Fever 企画書 (GDD)

星をモチーフにしたインフレ系パチンコゲーム。
TsukinoEngine（EnTT ECS / Jolt Physics / cereal Prefab JSON）上で作る。

## コンセプト

- **玉で星座を描き、本物の星を集める**パチンコ。星ゲットチャンスで盤面に現れる星釘を玉でつなぐと、88星座の星が1つ手に入る
- 星は実際の天文データ（位置・等級・スペクトル型・IAU の固有名）。遊びながら星と星座の名前を覚えられる
- 数字は和風単位（万・億・兆・京・垓…無量大数）を超えて宇宙単位までインフレする
- 基本は**手で打つアクティブなプレイ**。腕前（ハンドル強弱の狙い分け）が報われる

## コアループ

1. ハンドル強弱で玉を打つ（止め打ち・右打ちの狙い分け）→ 釘や入賞口で **星屑**（通貨）を獲得
2. スタート入賞 → **黄道十二宮リール**の抽選 → 当たりで **フィーバー「星詠みタイム」**（星屑の稼ぎ時）
   - 釘と入賞の星屑が ×3、チューリップの羽が開いて入りやすくなる（`FeverConfig.json` / `TulipWing*` の Prefab）
3. 盤面の下の段、スタート入賞口の左右にある **星の門** に入る → 抽選 → 当たりで **星ゲットチャンス**（ミニゲーム）
   - 88星座から1つが選ばれ、盤面にその形で **星釘** が出る。星座の線は薄いガイドとして現れ、両端の星をつなぐと金色に灯る
   - 星釘と重なる普通の釘は、チャンスの間だけ消える
   - 制限時間のうちに **全部つなげたときだけ**、星を1つ引ける。どの玉でつないでもよい
   - フィーバー中とリールが回っている間は、星の門は開かない
4. 引いた星を集める。初めてなら ★1、持っていれば ★+1、★5 なら星屑に換わる（→「星」「星座」）
5. 星屑で台を強化 → 進んだら **転生**（ビッグバン → 多元宇宙 …と多層構造）

## 操作

| 操作 | 内容 |
|---|---|
| Space 長押し → 離す | 押している間、強さのゲージが 0→最大→0 と往復する（1往復 `chargeCycleSeconds`）。離した瞬間の強さで1球打つ。狙った強さで離すタイミングが腕前 |
| マウス | 全ての操作ができる。盤面の長押しで発射、強化のカードで購入、左下のボタンで自動発射・星図・ビッグバン、星図のボタンで前後の星座とグループ |
| Tab | 88星座の星図の画面を開け閉めする（Esc でも閉じる）。開いている間は遊びが止まる |
| G | そろったグループの一覧を開く（右のパネルの「そろったグループ」を押しても開く） |
| Esc | 設定の画面を開け閉めする（星図を開いているときは星図を閉じる）。開いている間は遊びが止まる |
| 自動発射（強化で解禁） | 最後に手で打った強さを基準に打ち続けてくれるが、強さが `autoFireJitter` だけランダムに揺らぐ。溜めている間は止まる。星の門や星釘を狙うなら手打ちが必要 |

## 星

実際の天文データを使う。88星座の線をつくる星すべて（710個。そのうち IAU の固有名を持つ星が244個）が集める対象。

- **引き方**: 星ゲットチャンスを成功させると、つないだ星座の星から1つを引く（88星座すべてがチャンスに出るので、710個すべてが手に入る）。**明るい星ほど出にくい**（1等級暗くなるごとに `rarityBase` 倍出やすい）
- **名前**: 固有名のある星はカタカナ（例: メンカリナン、フォーマルハウト）、無い星はバイエル符号（例: けんびきょう座β）。引いたときに等級とスペクトル型（色）も出す
- **効果**: 持っている星ごとに全体倍率 ×(1 + `levelBonus` × ★)。明るい星ほど `levelBonus` が大きい
- **レベル ★1〜★5**。★5 の星を引くと、星の値打ち × `duplicatePayoutScale` の星屑に換わる
- 今後: スペクトル型ごとの属性、M型の **超新星化**

## 星座

88星座すべて。星座の線をつくる星を全部持つと、**その星座の固有の効果** が発動する（`CollectionEffectSystem`）。

| 種類 | 効果 | 割り当て |
|---|---|---|
| lotteryChance | フィーバー当選 +0.4% | 黄道12星座 |
| pocketPayout | 入賞の星屑 ×1.15 | 水や船の星座（くじら・うみへび・旧アルゴ座…） |
| pinPayout | 釘の星屑 ×1.15 | 道具の星座（ポンプ・とけい・けんびきょう…） |
| starChance | 星ゲットチャンス +1% | 鳥の星座（わし・はくちょう・ほうおう…） |
| feverDuration | フィーバー +1秒 | 人物の星座（オリオン・ペルセウス・ヘルクレス…） |
| global | 全体倍率 ×1.05 | それ以外 |

- 効果は星の平均レベルが1上がるごとに `effectLevelBonus`（1割）ずつ伸びる
- **88星座が全部そろう** と全体倍率 × `allCompleteMultiplier`（10）
- 星ゲットチャンスで盤面に出す星は、星座ごとに最大12個。多い星座は明るい星から線でつながる順に選ぶ（抽選の対象は線の星すべて）

### 星の門の抽選

玉が星の門に入ると、画面が暗くなり星座ルーレットが始まる。88星座の線画が入れ替わって止まり、星が1つずつ灯って全部つながると当たり。止まった星座がそのまま星ゲットチャンスの星座になる。あと1つで消える惜しい外れ、外れたと見せてからの復活、金色の予告がある。当選確率は筋書きに関係しない（`StarGateFxSystem`）。輪が金色なら当たりやすい。星詠みタイム中やリールの回転中でも抽選する。星詠みタイムと重なったときの BGM は「木星」のまま。抽選の間とチャンスの間に入った玉では抽選しない

### 星を手に入れた演出

星を引くと、画面の中央に大きな星が弾んで現れ、名前を見せたあと、弧を描いて星図のボタンへ吸い込まれる（`StarGetFxSystem`、遊びは止めない）。明るい星ほど派手になる。星屑に換わった星は星屑のカードへ飛ぶ。星の横には星座の形のカードを出し、星座の中のどの星かを脈打つ光で示す。星図のボタンにはまだ見ていない星の数を赤い丸で出し、星図を開くと一番新しい星を見せ、閉じると消える

### 88星座の天球（Tab）

天球の中心に立ち、空を見回して集めた星を眺める画面。開いている間は遊びが止まる

- 開くと暗転し、下から空を見上げるように星が浮かび上がる
- 本物の 3D。カメラを盤面から遠く離れた天球の中心へ移す。盤面はカメラの遠い面より外へ出るので描かれない。閉じると元の位置へ戻す
- 持っている星はスペクトル型の色でブルームで光り、持っていない星は淡い点。そろった星座の線は金色で太くなる
- ドラッグ・WASD・矢印で見回す（手を離すと慣性で少し滑る）。ホイール・Q/E で拡大（視野を狭める）
- 未入手の星は全部同じ淡い点で、名前・等級・色は手に入れるまで隠す。星座の線と名前は集める目標なので見せる
- キーボードだけでも見られる。画面の中央の照準に一番近い星座の名前が出て、Space・Enter で選ぶ。C/V で星座の星を明るい順に移り、R/F でパネルを送る
- クリック・Z/X で星座を選ぶと、そちらへ滑らかに回り、右のパネルに説明を出す。パネルは空に半透明で重なる
- **G でグループの一覧** に切り替える。15のグループのそろった数を並べ、選んだグループ（Z/X）の説明・効果・属する星座（そろったものに ✓）を出し、星図でそのグループの星座を目立たせる
- 星にマウスを乗せると、名前・呼び名・等級・色・星座・★のレベルを吹き出しで出す。持っていない星も見られる
- 星座を選ぶと、固有名のある星と明るい星から順に `maxStarLabels` 個まで、星の横に名前を添える
- 星座の図鑑の文章（神話・見つけ方・天文の話題）を右のパネルに出す。最初から読める。文章は `Tools/SkyCaptions.py` に書き、`Tools/BuildSkyCatalog.py` が `Constellations.json` へ入れる
- パネルの上のホイールで、文章と星の一覧を送る
- 星図の座標と投影は `Core/SkyMath`（エンジンに依存しないので単体テストする）。星の向きは内側から見た向きで、赤経が大きいほど左

### データの作り方
- `python Tools/BuildSkyCatalog.py --download` で元データを `Tools/SkyData/` に取り（コミットしない）、`python Tools/BuildSkyCatalog.py` で `Assets/Data/Stars.json` / `Constellations.json` を作る。続けて `python Tools/GenerateBoardLayout.py`
- 和名と星座の効果の割り当ては `Tools/SkyNames.py` の表
- 元データのクレジットは `Docs/Credits.md`

## 強化ツリー

星屑を払って台を強化する。数字キー 1〜9 で、`Assets/Data/Upgrades.json` の並び順に購入する。

- 値段は `baseCost × costGrowth^Lv`。BigNumber で計算するので、double を超えても上がり続ける
- 効果の積み上がり方は2種類
  - `multiply`: (1 + 値)^Lv。倍率系に使い、上限なしで積み上がる。インフレの源
  - `add`: 値 × Lv。確率や秒数に使い、上限を付ける
- 効果は `UpgradeEffectSystem` が毎フレーム計算し直す。データを書き換えると実行中でもすぐ反映される

| キー | 強化 | 効果 |
|---|---|---|
| 1 | 星屑の釘 | 釘の星屑 ×1.25/Lv |
| 2 | 輝く入賞口 | 入賞の星屑 ×1.3/Lv |
| 3 | 幸運の星回り | 当選確率 +1%/Lv（上限10） |
| 4 | 星詠みの延長 | フィーバー +5秒/Lv（上限8） |
| 5 | 星の門の幸運 | 星ゲットチャンス +2%/Lv（上限10） |
| 6 | 自動発射 | Lv1 で解禁。間隔 2.4秒 × 0.85^Lv（Lv1 で約2秒、上限 Lv12 で約0.34秒） |
| 7 | 精密照準 | 自動発射の揺らぎ ×0.8/Lv（上限5） |

数字キーとカードは長押しで続けて買える。だんだん速くなり、星屑が足りなければ貯まるまで待つ。値は `Prefabs/Config/UpgradeShopConfig.json`。

強化レベルはセーブされ、ビッグバンで 0 に戻る。

## UI

よくあるゲームの HUD の型に合わせ、均一さと動きのなさを避ける。

| 場所 | 中身 |
|---|---|
| 左上 | 財布のカード（星屑の大きな数字、全体倍率と宇宙定数のピル、次の宇宙定数までのバー） |
| 盤面の上部 | 十二宮リール（液晶のつもり）と保留の光の玉。フィーバーと星ゲットチャンスの間はその上に帯が滑り込む |
| 左 | 強化ショップのカード（キーのバッジ・名前・Lv・効果・値段） |
| 右 | 星図（そろった星座・グループと集めた星の数、その下に最近手に入れた星。チャンス中は盤面の星と、つないだかどうか） |
| 左下 | 発射ゲージ（色が 青 → 金 → 赤。最後に打った強さの印） |
| 下 | 操作のキーのチップ（Tab で星図） |
| 右下 | 通知のトースト（新しいものが下に入り、古いものは押し上がる。縁の色は出来事の良し悪しで変える） |
| 中央 | 大見出し（フィーバー開始・星座完成・ビッグバン）。弾みながら現れる |
| 盤面の上 | 星屑が入った場所から浮かぶ数字（金額で大きさ、出どころで色）と、星をつないだときの粒子。入賞口の上の名札（「スタート」「チューリップ」「星の門」。入賞口の色の文字） |

**動きの決まり**
- 待機中のパネルは、それぞれ周期と位相をずらしてわずかに漂う。全部が揃って動くと機械的に見えるため
- 出てくるときは時間差で、少し行き過ぎて戻る（OutBack）。カードや通知はわずかに傾け、定規で引いたような揃い方を崩す
- 星屑の数字は一瞬で変えず、桁の上で追いかけて転がる。大きく増えたら弾み、払ったら一瞬赤く沈む
- 状態が変わった瞬間に反応する。リールは止まった瞬間に弾み、リーチで枠が脈打ち、買える強化は縁が呼吸する

並べ方と色は `Prefabs/Hud/**` と `Prefabs/Config/HudLayoutConfig.json` / `HudFxConfig.json` にあり、ホットリロードできる。
素材は `Tools/GenerateUiTextures.py` で作る。

## 音

- BGM はクラシック。場面を状態から決めて、曲の音量を動かしてクロスフェードする（`BgmSystem`）
  - 優先順位は上から
    - 星図: ドビュッシー「月の光」
    - 星ゲットチャンス: モーツァルト「きらきら星変奏曲」のオルゴール
    - 星詠みタイム: ホルスト「木星」の賛歌の頂点 → 終結部
    - リーチ: ホルスト「火星」の最も強い所
    - 通常: ホルスト「金星」
  - 星詠みタイムは「木星」の賛歌の頂点が、既定の45秒の終わりに来るように切り出している
  - リーチ・チャンス・フィーバーの曲は、場面が始まるたびに頭から鳴る。通常と星図の曲は裏で進み続ける
- リーチになる変動は、右のリールが `reachExtraDuration`（3秒）長く回る。リーチの間を作り、曲を聴かせるため
- 効果音はイベントと状態の変化から鳴らす（`SfxSystem`）。音と音量は `AudioConfig.json`
  - 釘の音は玉が多いと連発するので、`pinMinInterval` で間引く
  - 星をつなぐ音は、つなぐたびに音階を上がる
- 音量は設定の画面（Esc か右下の「設定」）のスライダーで変える。M で消音、F6 / F7 で BGM、F8 / F9 で効果音も変えられる。セーブに残る
- 設定の画面では、キー操作の表示（画面下のキーと、パネルのヒント）も出し入れできる
- 音は裏のスレッドで読み（エンジンの `AssetManager::LoadAsync`）、読み終えた音から鳴らす。読めるまでは無音のまま遊べる
- 曲と効果音の作り方は `Tools/BuildMusic.py` と `Tools/GenerateSfx.py`、権利は `Docs/Credits.md`

## 止まった玉

玉は閉じたチューリップの羽の上などで釣り合って止まることがある。`stuckSeconds` ほぼ動かない玉を左右へ押し、`stuckMaxNudges` 回押しても動かなければアウトにする（`BallStuckSystem`）

## 盤面の見た目

- 上の半円の壁は、玉の当たりは短い箱の列（`ArcCollider`）、見た目は滑らかな1枚のモデル（`Arch`、`Tools/GenerateArchModel.py`）に分けている。箱をそのまま見せると継ぎ目の角が飛び出す

星空の中で、光る玉が星屑の尾を引き、釘が星のように瞬く。

| もの | 見た目 | 調整する場所 |
|---|---|---|

| 星釘 | 十字の光芒が呼吸し、周りを点光源で照らす。つなぐと金色に強まる | `Prefabs/StarPin/GlowHalo.json` |
| 星座の線 | フィーバー開始時に全部の線が薄い青で現れ、両端の星がつながると金色に灯ってブルームでにじむ | `Prefabs/Config/StarLinkConfig.json`（太さと色） |

| 背景 | 遠い星空と2つの星雲を奥行きを変えて重ね、盤面の板にも淡い星空を敷く。流れ星がときどき横切り、フィーバー中は流星群になる | `Prefabs/Space*` / `BoardStarfield`、流れ星は `CosmicFxConfig.json` |

素材は `Tools/GenerateSpaceTextures.py` で作る。

## インフレと転生

- 内部は BigNumber（仮数 double ＋ 指数 int64）。上限は実質なし
- 表示は 万 → 億 → 兆 → 京 → 垓 → 秭 → 穣 → 溝 → 澗 → 正 → 載 → 極 → 恒河沙 → 阿僧祇 → 那由他 → 不可思議 → 無量大数。その先は指数表記
- 転生は多層: **ビッグバン**（宇宙リセット → 宇宙定数）→ **多元宇宙**（さらに上位）

### ビッグバン（実装済み）
- **B キーを2回**押す（1回目は確認だけ）。フィーバー中と星ゲットチャンス中はできない
- **得るもの**: 宇宙定数 Λ
  - 獲得量は `floor((この宇宙で稼いだ累計 ÷ 100万)^0.5)`
  - 累計は星屑を使っても減らない
- **効果**: 全体倍率 ×(1 + 0.1 × Λ)。永続する
- **リセットされるもの**: 星屑、強化、この宇宙の累計、抽選の保留、盤面の玉
- **残るもの**: 星のレベル、集めた星（星座のそろい具合も）、宇宙定数
- **案内**: できるようになると大見出しと音で一度知らせ、できる間はボタンと B×2 の案内が弾む。星屑の下の文字は金色になり、実行後の全体倍率を見せる。この文字を押しても確認画面が開く。星詠みタイムと星ゲットチャンスの間は知らせず、終わってから出す
- 数値は全て `Prefabs/Config/PrestigeConfig.json` にあり、ホットリロードできる

### 天体（実装済み）
- 星座の線に入っていない有名な星と、星団・星雲・銀河の42個。一覧は `Tools/SkyObjects.py` にあり、`Tools/BuildSkyObjects.py` が `Assets/Data/SkyObjects.json` を作る
- **ビッグバンのたびに未入手から1つ必ず手に入る**。同じ天体は出ない。全部そろえば何も出ない
- レア度はコモン・レア・スーパーレア・レジェンドの4段階。重みは `baseWeight × 10^(growth × 桁)` で、桁はこの宇宙の累計がビッグバンできる量の何桁上か。稼ぐほど高いレア度が出やすい。確率は確認画面で実行の前に見られる
- 天体ごとに効果があり、持っている間ずっと効く。種類は星座の効果と同じで、量はレア度で決まる
- 星図の空に絵で並ぶ。未入手は全部同じぼんやりした光で、名前・種類・効果・文章は手に入れるまで隠す（レア度と空の位置だけ見える）。絵は `Tools/GenerateSkyObjectTextures.py` が作る
- `T` か「天体」のボタンで図鑑を開く。照準を天体に合わせて Space・Enter でも開く。図鑑では Z/X で一覧を移り、C/V で同じ種類へ跳ぶ
- 数値は `Prefabs/Config/SkyObjectConfig.json` にあり、ホットリロードできる

### セーブ（実装済み）
- 保存先は `Saves/save.json`
- 起動時に読み込む。保存するのは30秒ごと、強化の購入・星座の完成・ビッグバンの直後、終了時
- 保存は一時ファイルを経由して入れ替える。読めないセーブは `.bad` に退避してから新しく始める

## 縦切り後に入れる要素

- 特殊な玉: 隕石玉（重い）、彗星玉（軌跡にも当たり判定）、中性子星玉（よく跳ねる）
- ランダムイベント: 日食、流星群、オーロラ、惑星直列（確変）
- 放置報酬（演出は「赤方偏移」）
- 星座図鑑 UI、強化ツリー、転生 UI

## 縦切り（最初のマイルストーン）の範囲

「打つ → 星屑 → 抽選 → フィーバー」と「星の門 → 星ゲットチャンス → 星を引く → 星座がそろう」が遊べること。

- 盤面（釘・壁・入賞口・アウト口）
- ハンドル強弱での発射と、仮の強化キーによる自動発射の解禁
- 抽選とフィーバー（星屑の稼ぎ時）、星ゲットチャンス（88星座）、星の抽選、星と星座の効果
- 調整値（Config）と星・星座データのホットリロード

## アーキテクチャ方針

- **Component はデータのみ / System はロジックのみ**。System 間の連絡は EventBus のイベント
- **System の調整値は `XxxConfigComponent` として Prefab JSON に置く**。System はコードに定数を持たない
- 星・星座のマスターデータは `Assets/Data/*.json`。保存すると実行中に反映される（ホットリロード）
